- **Visual Type**: Sequential Closed-Loop Pipeline / Lifecycle Phase Map (`type-process.md` / `type-state.md`).
- **Complexity Budget**: 5 stages, 5 forward transitions + 1 return loop (6 arrows total), 1 focal accent node (Stage 04).
- **Geometry Grid**: 4px divisible coordinates, margins, and gaps.
- **Palette**:
  - `paper`: `#0d1117` with 22x22 dot matrix pattern (`r=0.9` at 10% opacity, pattern opacity 0.55).
  - `paper-2`: `#161b22` for standard stage card containers.
  - `rule`: `#30363d` hairline borders (zero shadows).
  - `ink`: `#f0f6fc` primary headings, `#8b949e` mono sublabels and secondary tags.
  - `accent`: `#f08a59` (warm burnt-tangerine) reserved strictly for the focal quality gate (Stage 04: Empirical Testing) and return feedback loop.
- **Connectors**:
  - Orthogonal forward lines with `r=8` right-angle Q-bezier turns on the return feedback loop.
  - Opaque text masking rect (`fill="#0d1117"`) with a 6px stroke clearance gap behind the label `"DEFECT DETECTED: ROOT-CAUSE FIX"`.
  - Accessible SVG contract: `role="img"`, `aria-labelledby`, prefixed `<title>` and `<desc>`.
